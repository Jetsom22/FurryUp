# 로켓몬스터 마스터 데이터와 리소스

수강생 42명이 설계한 몬스터와 기술, 그것을 담은 마스터 표, 그리고 그림
파일입니다. 게임 코드는 안 들었습니다. 표와 자산만 있습니다.

뜬 자리는 `HK_RocketMonster` 의 `4ab97ef` 입니다.

<br>

## 무엇이 들었나

```
master/   사람이 고치는 원본. 구글 시트 여덟 탭을 CSV 로 뜬 것
data/     기계가 읽는 생성물. master/ 에서 만들어진다
img/      실제 그림 파일 86장
```

**둘 중 하나만 쓰면 됩니다.** 새 프로젝트가 데이터를 그대로 읽어 쓰기만 하면
`data/` 만 보면 되고, 표를 고쳐 가며 쓰려면 `master/` 가 원본입니다. 다만
`master/` 에서 `data/` 를 만드는 도구는 안 들었으므로, 고쳐 쓰려면 그 변환을
새로 지어야 합니다.

<br>

### 머리글이 세 줄입니다

CSV 첫 세 줄이 전부 머리글입니다. 넷째 줄부터 자료입니다.

```
리소스 행 ID,리소스 ID,규격,파일 경로     ← 1줄. 사람이 읽는 이름
id,res_key,kind,path                      ← 2줄. 기계가 읽는 칸 이름
int,string,enum,string                    ← 3줄. 자료형
1,RES_CHR_001,ST_F,img/character/…        ← 4줄부터 자료
```

읽을 때는 **둘째 줄을 칸 이름으로** 삼습니다.

### 밑줄로 시작하는 칸은 메모입니다

`_name` 이나 `_owner` 나 `_설명` 처럼 밑줄로 시작하는 칸은 시트에서 사람이
보려고 둔 것입니다. 판정에 안 들어가므로 읽을 때 건너뛰어도 됩니다.

### 글자는 전부 `string.csv` 에 있습니다

`character.csv` 의 `name` 칸에는 「알코」가 아니라 `CHR_001_NAME` 이 들어
있습니다. 그 열쇠로 `string.csv` 를 찾으면 한국어와 영어가 나옵니다. 표를
하나 고쳐서 두 언어가 같이 따라오게 하려고 이렇게 나눴습니다.

`export` 하는 것뿐이라 필요하면 JSON 으로 바꾸기 쉽습니다.

## 몬스터 하나를 읽는 순서

`characters.json` 을 쓰면 이 걸음이 이미 다 지나가 있습니다. 아래는
`master/` 에서 직접 읽을 때의 순서입니다.

1. `character.csv` 에서 `chr_key` 로 한 줄을 찾습니다
2. 그 줄의 `name` 과 `desc` 를 `string.csv` 에서 글자로 바꿉니다
3. 그 줄의 `skill_group_key` 로 `skill_group.csv` 를 찾아 기술 네 자리를 얻습니다
4. 각 자리의 `skill_key` 로 `skill.csv` 를 찾습니다
5. 그 기술의 `effect_group` 으로 `skill_effect.csv` 를 **여러 줄** 찾습니다
6. 각 효과의 `kw` 와 `grade` 로 `grade.csv` 를 찾아 실제 수치를 얻습니다
7. 그 줄의 `res` 로 `resource.csv` 를 찾아 그림 경로를 얻습니다
